CAF 0.1.1 fixes feasibility, decomposition, and comparison errors in the code and
adds regression coverage. It preserves the published paper and the
pre-maintenance repository snapshot
`356c1852c65a185b05aed040052c5c3f750991bd`.

- CAF starts from a feasible selection and validates explicit warm starts.
- Recursive community detection uses global asset indices and unique labels.
- Custom-K experiments compare portfolios with the same exact cardinality.
- Paired sign tests omit ties; q-sweep baselines are reoptimized at each q.
- Zero budget/risk parameters retain their meaning; risk-rebalancing options
  operate on actual community groups.
- SQA uses the documented nonzero-field `linear_normalized` schedule, version 1.
- QAOA decoding modes and experiment versions are explicit in new summaries.

Ordinary QAOA's positive RZ convention is retained. A last-mixer-parameter shift
proves equivalence of its unrestricted variational family to the direct target
Hamiltonian convention; regression tests cover this identity and BQM scoring.
The warm-start circuit is preserved for a separate controlled evaluation.

Validation: 63 tests passed; small classical exact-K and q-sweep runs, QAOA,
nonzero-field SQA, both decoding modes, and frozen-ablation execution completed.
These are functional checks, not paper-scale numerical reproductions. Commercial
solver licensing and quantum hardware execution were not validated in this
release preparation.

Community detection, risk rebalancing, initialization, statistics, and the new SQA
protocol can change numerical outputs. Preserve original experiment artifacts and
identify the code version and protocol when comparing new runs. This code release
does not assert that the paper's conclusions changed or that all historical
numbers have been reproduced. See `CHANGELOG.md` and
`docs/maintenance-0.1.1.md` for the complete scope and protocol boundaries.
